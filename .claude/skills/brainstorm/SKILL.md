# Brainstorm

## When to use
- User asks for ideas, options, alternatives, naming, "what if" exploration.
- Trigger phrases: "brainstorm", "ideate", "give me options", "name some", "what are the ways to", "explore".
- Use BEFORE planning when the problem is not yet well-shaped.

## Workflow

### 1. Frame
- Restate the goal in one sentence. State the constraint(s).
- State what is fixed (must keep) vs. what is open (can change).

### 2. Diverge
- Generate at least 5 distinct options, ideally across categories:
  - Conventional / standard
  - Adjacent / borrowed from another domain
  - Minimal / "do nothing" baseline
  - Maximum / ambitious
  - Reversible / cheap-to-pilot
- For each option: 1-2 line description, key tradeoff, when it fits.

### 3. Stress-test
- For each promising option: what's the failure mode? What does success look like? Cost? Reversibility?
- Cross-cut: pair options, look for hybrids.

### 4. Surface Decision
- Recommend one option with a one-sentence reason.
- List 1-3 follow-ups the user must decide before plan.

## Anti-patterns
- Listing 10 surface-level ideas without tradeoffs.
- Recommending without evidence or reasoning.
- Hiding the "do nothing" option when it's actually competitive.

## Check
- Goal restated, constraints surfaced, options span the space, tradeoffs named, recommendation with reason.
